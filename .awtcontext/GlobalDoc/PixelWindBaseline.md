# 逐像素基础力场与风模拟基准

日期：2026-10-12。AWT 任务：实现逐像素力场与风场基准。

## 职责和单位

- `ForceField` 为独立、连续、1:1 像素向量存储，无风、渲染或引擎依赖。当前以单位质量加速度（像素/秒²）表达力；基础场可通过 Set/Add/Fill 编辑。
- `World` 持有基础场。旧方向编辑接口映射为方向乘3600；显式连续编辑后，CellState::Force 是兼容元数据，不是实际连续力的来源。材料移动只搬 Type；不再经 SetCell 重置源/目标的连续基础场。
- `Environment` 将空气速度转换为独立的风贡献，`a_total = a_base + 60*u_air`；实际移动沿用 `a_total/60` 与±30死区。不是物体惯性积分，也不是物理空气阻力定律。
- `GetForce` 对每个世界像素给出合成受力，关闭/重建风不影响基础场。F1仍在帧首采样合成场写入渲染快照，Draw不读实时 World。普通 WorldState 发布不包含新连续基础场。

## 参考求解器

`PixelWindField` 使用与像素等大的MAC单元、共享面速度和双精度存储。X面位于(x,y+1/2)，Y面位于(x+1/2,y)。外边界周期相接。非空材料都是硬固体，面两侧只要有固体则该面法向速度严格为0。界面切向采用自由滑移近似；插值保留邻接固体的零法向面，仅排除完全埋入固体的插值点。

扩散为显式中心差分；随后半拉格朗日平流、背景松弛和压力投影。内部时间步限制每轴回溯不超过0.5像素、νdt不超过0.2。短回溯检查终点及中点，避免一像素墙体穿越。压力算子与散度/梯度共用同一面连通掩码；Jacobi预条件CG从零压力开始，处理不连通空气区域的半正定系统。压力数组存储的是速度修正势，而非直接可作牵引力的物理压力。

`GetReport` 返回实际投影后RMS散度、最大散度、累计迭代次数、内部子步数和Converged。默认容差1e-6，单次投影最多4096迭代；耗尽预算明确返回未收敛，不能把该输出当作已验收的参考解。RMS达标不意味着每个像素的最大散度也低于同一数值，报告同时保留最大值。`SetFaceVelocities`用于可复现初态，`FaceX/FaceY`用于通量测量。

几何每固定步开始、材料移动后同步。固体内部纯空气采样为0；受风适配器使用暴露邻格空气平均速度。此版本将运动视为几何的分步重建，没有移动壁面排流、压力牵引或固体/空气总动量守恒，不能用于声称动态刚体耦合精确。活动区域外风贡献为0。参数每维1～2048，内存约85字节/风像素，加上基础力场8字节/世界像素；不含原格子与渲染数据。

## 比较工具与结果

工具源码：`Pixel/Benchmarks/PixelWindBenchmark.cpp`。输入尺寸、步数及可选逐像素采样CSV路径。场景：空区、贯穿风区的单像素墙、墙中央一像素开口。固定初态向右8像素/秒，ν=0、阵风=0、松弛=0，固定外部步长1/60秒。静态材料不移动。旧粗场为32×16、默认有限阻力；新参考解为硬边界。因此RMSE同时包含模型与分辨率差异，不等同于网格收敛误差。

最终实现用clang++ -std=c++20 -O2编译，本机单次运行，记录初始化及单步均值；不是跨运行统计置信区间。64×48运行4步，最终CSV如下：

最终 CSV 与逐像素样本位于任务 Artifacts。`benchmark-1024.csv` 是修正边界插值之前的过程测量（狭缝单步约125秒），不可冒充最终代码数据；`benchmark-64-final.csv`、`benchmark-1024-setup.csv`、`benchmark-1024-final.csv`对应修正后实现。即使收敛的初始化很快，狭缝中集中流速可增加CFL子步，持续演化仍可能昂贵。

## 方案判断

沿用已有 WindSimulationAlternatives.md 的四类方案，优先用本基准比较粗NS+局部模型的近场误差与成本。程序化模型适于可控视觉，但多障碍通量分配需验证；自适应NS适合保留狭缝连通，复杂度集中在跨层压力/通量；GPU LBM适于规则网格并行，但稳定性与CPU交互同步需实测。上述三种新路线未实现或实测，不能据本轮数据给出性能排名。

## Code review

按code-design-style中的普通审查流程完成，范围为本轮全部diff、新文件、World/Environment调用链和现有发布/风场测试；审查基线为工作区HEAD，保留先前未提交的方案文档。由实现者完成普通review，未声称独立或对抗性审查。

发现并处理：

1. 近壁采样偏快：最初插值只对Open面重归一化，忽略硬边界的零面。现在将采样支持与流通掩码分离，保留邻接固体的零面，并加入中心速度等于两面平均的回归。
2. 外力被移动重置的风险：新增连续场后，原移动链调用SetCell会重新映射兼容方向。改为私有MoveMaterial只搬Type，测试源和目标连续场均保留。
3. 扩散/平流组合稳定性：旧态Laplacian直接加在平流结果上不保证单调。当前先独立扩散再平流，并对扩散采用稳定步长，增加Fourier解析离散解验证。
4. 诊断被几何同步覆盖：无变化的SetObstacles曾重置Step报告。现在无变化直接返回，材料更新所需投影追加到当前报告，保持子步与失败证据。

最终检查未发现尚需修复的已证实阻断缺陷。上述验证范围不覆盖完整连续流体真值；周期外边界、静态几何耦合、旧移动死区及昂贵CPU成本是明确保留的模型限制。

方法参考：Bridson / Müller-Fischer, Fluid Simulation (SIGGRAPH 2007), https://www.cs.ubc.ca/~rbridson/fluidsimulation/ 。本实现使用对角预条件，不是资料示例的MIC预条件。

### 最终大尺度单步补充

最终实现单独运行1024×424、1步（额外1/60秒）完成：空区28.20ms、整高墙25.43ms、单像素狭缝148379ms。狭缝初始化6.79s，初始化与演化合计35903次压力迭代，最终RMS9.90e-7、最大1.76e-5、固体面通量0、Converged=true。差异反映狭缝强集中流速与多次压力投影的成本；不承诺实时。测量不包含方块运动、渲染或GPU同步，单次运行还受并行验证负载影响。最终增加了World接入回归：编辑/移除障碍同步、30/120Hz固定步一致性、切换求解器只启用一个风源并保留连续基础力。

## code-design-style 职责重构与独立复核（2026-10-12）

按用户后续要求调整程序设计，保留上文数值算法及玩法参数：

- `WindSimulation` 用 variant 独占当前后端，集中处理切换、采样、脉冲及材料更新前后的风推进；替代 Environment 中两个可独立启用的求解器和分散分支。先构造新后端再提交，配置失败保留原状态。
- `WindTypes` 保存共用数据类型，逐像素求解器不再依赖粗场头文件；固体表面暴露空气采样从数值求解器移至 WindSimulation 适配层。
- `FieldResponse` 集中表达方向到加速度、风贡献、移动速度与死区规则；Environment 保留固定步与材料移动调度，World 持有基础场。没有新增通用插件框架或渲染依赖。
- 保留旧方向元数据契约、禁用风时脉冲抛错及固定步余量。诊断 getter 仍为 const 引用，重配置/关闭后不能继续持有；独立审查检索现存调用方，没有跨切换保留引用的用法。

独立 reviewer 只读比较本轮重构前快照与最终代码，检查全部 getter 调用方、异常事务、生命周期、周期邻域采样和材料反馈顺序。未发现需要修复的问题，无未决意见。该审查未冒充测试；另由独立验证 agent 执行最终代码验证：

- `cmake --build build-cpu -j4 && ctest --test-dir build-cpu --output-on-failure`：退出0，6/6通过。
- `cmake --build build-review/cpu-sanitized -j4 && ctest --test-dir build-review/cpu-sanitized --output-on-failure`：退出0，6/6通过。
- `cmake --build build-runtime --target Pixel PixelRuntimeSmoke Axiom -j4`：退出0；重复 ImGui 静态库链接警告，不影响构建。
- 新增双向配置失败保留旧后端、非活动诊断为空、禁用后力贡献与脉冲错误语义的回归。
