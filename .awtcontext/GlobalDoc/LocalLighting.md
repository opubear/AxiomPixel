## 火把操作与世界状态

调试角色按 2 持有火把，普通角色按 7。左键瞄准实心地面或其上方的空气格，插下一支点燃的火把。目标和支撑须已驻留，目标须为空且无角色或设备，拒绝时保留背包数量。Shift＋右键点燃或熄灭地上火把，右键回收，满包时保留地上的火把。再次放下时点燃。地上火把锚定于格坐标，挖掉支撑也可继续访问和回收。 [角色初始背包](Items.md#角色初始背包)

库存用 `ItemId::Torch`（1140）保存数量。地上火把使用普通区块中的材料 ID 72（点燃）与 73（熄灭），点灭不改变格子上的力。火把无角色碰撞，仍占一个材料格。显式持久会话的旧存档可以读取，新存档沿用现有区块与 Gameplay v6 格式；新版本写出新增内容 ID 后需要支持这些 ID 的游戏读取。默认临时会话的退出与 R 重置仍遵守原有边界。
