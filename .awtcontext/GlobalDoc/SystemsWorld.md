# 世界、环境与地区生态

状态核对：2026-11-14。本文是系统管理入口；规则详情以链接的现行合同为准，测试结果按各功能合同的带日期证据查阅。

## 玩家体验与系统目标

玩家探索有地区差异的自然世界，开采和改造材料，观察水、火、风与推力的反馈，并把环境规律用于构式和家园。地区差异应同时解释地貌、生物分布和画面，不能只靠背景贴图制造差别。

当前可体验的闭环是“进入地区 → 观察地层和生物 → 开采或施放构式 → 看到同一世界状态变化”。默认游戏是开发试玩会话，重启或 R 创建新世界；跨次续玩仍未开放为默认产品流程。

## 设计与数值边界

- 气候是世界种子、生成版本和坐标决定的稳定基线，不是实时天气。温度和湿度是指数，不是摄氏度或实测百分比。
- 昼夜与季节按完整模拟步推进，暂停/预算等待冻结，远区共享当前日历；尚未影响气候指数、结冰、生长或生物作息。
- 森林树木是真实方块，可开采；小草／野花、沙漠灌木、雪山小石是无碰撞装饰，不提供资源。
- 沙土、雪和冰当前是静态地层；没有逐粒落沙、融化／结冰、树木生长或整体倒树。
- 水为有限材料，不自动补水；没有压力管道、体积分数、侵蚀、河网或海洋模拟。蒸汽与火是元胞形态规则，不代表热力学或燃烧反应。
- 风模型精度不同。粗NS允许有限穿流，程序风／局部近似不保证无散，自适应与CPU LBM不承诺实时；不把调试效果作为精确流体物理承诺。
- 生物候选由地区和物种固定身份管理，休眠保存状态；不提供繁殖、迁徙或周期补生。活动槽和地区记录均有容量上限，超大世界存储仍需专门设计。
- 玩家相机加载远方只加载可见地形，不因此生成人口；暂停不推进生态候选。

## 当前试玩与配置入口

1. 默认启动 Natural v2；F2 的 World generation 选择下一世界的生成器和种子，R 重建。
2. 右键开采；左键统一使用快捷栏当前手持物。方块在面前放置并消耗对应资源；F2掉落木棍后走近拾取，可用它施放构式。
3. F2 Environment 切换风策略并查看完整窗口覆盖尺寸；F1 查看合成力方向。颜色表达方向，不表达强度。
4. 调试元素笔刷为 Shift+2 水、Shift+3 蒸汽、Shift+4 火，Shift+1 退出笔刷。数字1–7为快捷栏；投放不消耗库存，不能作为正式制作／资源循环的一部分。
5. F2 显式创建力场育圃，用实际资源、设备和植物反馈验证环境玩法，见[力场育圃](ForceGarden.md)。
6. 快捷栏查看季节、日期与时间；F2 `Day / night and seasons` 切换晨午昏夜、季节、日长/季长及日历速度。晨昏按钮按当天目标时刻计算，季末与短季节下也可直接预览，重复点击保持同一时刻。

当前默认运行；全局暂停、固定步与排队动作规则以[工程操作入口](../../README.md)及[独立模拟线程](../../Docs/Architecture/SimulationThread.md)为准。动作入队不代表已生效，环境和角色在完整固定步提交后统一可见。

## 跨系统责任

Simulation 拥有地形、材料、生成与气候；Gameplay 查询这些事实决定角色、生物、构式、设备与资源结果；Render 只表现已提交状态。新环境规则应从目标世界坐标取事实，不能从背景颜色、摄像机位置或装饰可见性推导玩法。

Natural v1 与 Flat v1 的旧生成结果保持兼容；改变 v2 的固定生成参数必须新增版本。新材料必须同时考虑材料定义、开采产物、资源映射、保存与旧程序拒绝语义，不能只增加贴图。

默认临时世界与显式持久会话是不同产品边界。底层检查点保存能力见[检查点](Checkpoints.md)，不能据此宣称玩家重启会自动恢复世界。

## 后续决策与验收切面

| 尚未交付或待决定 | 进入开发前需明确 | 可观察的验收方向 |
|---|---|---|
| 动态天气／湿度点火 | 静态气候与动态环境的叠加、资源消耗、失败回执和存档 | 同地点规则可重现，天气变化通过正式提交影响结果 |
| 生态长期演化 | 补生、繁殖、迁徙是否需要；离线时间与地区存储预算 | 死亡记录、身份、返区恢复与新规则不冲突 |
| 更多材料建造 | 放置选择、资源成本、碰撞和占用合同 | 所见材料与实际消耗一致，失败不扣料 |
| 流体精度与规模 | 玩法需要哪类误差、目标设备和时间预算 | 先定义玩法场景，再比较质量和成本，不能只比较FPS |
| 默认长期存档 | 明确产品恢复入口和失败体验 | 世界、角色、生态、设备、程序和权限来自同一提交 |

这些是范围缺口与决策项，不是已经批准的排期。新增任务应先选择玩家场景，再细分到相关领域，并把已交付变化回写本页和对应合同。

验证入口：`Pixel.Generation/Biomes/Population/Elements/Liquids/WorldUnits/SpatialStorage` 及相邻合同；真实画面对应 `--terrain-only`、`--biomes-only`、`--elements-only`。最近实际结果分别见原合同的带日期记录；本页不复制易过时的通过数量。
