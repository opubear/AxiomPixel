# 角色、怪物与战斗系统

状态：已有可运行切片，居民生活与成长仍待设计。核对日期：2026-11-10；依据当前工作区，包含尚未提交的功能。本文从玩家体验组织现状，精确接口见[Actors](Actors.md)和[怪物合同](../../Docs/Monsters.md)。

## 玩家体验与闭环

玩家在自然世界移动、跳跃、游泳和探索，遇到适应该地区的怪物，通过构式弹体战斗。攻击有前摇和距离限制，地形可阻隔视线；玩家能通过移动与地形改变接触结果。木头人提供可重复的安全命中测试。

当前闭环为：探索地区 → 遇敌 → 瞄准施放／躲避 → 怪物死亡或玩家复活。它还没有“击败 → 掉落 → 装备成长”的奖励循环，也没有居民交流、居住需求或社会关系。

## 系统分项与当前规则

| 分项 | 已实现 | 当前限制 |
|---|---|---|
| 主角 | A/D移动、Space跳跃/水中上行，身体碰撞；启用怪物目录时100生命 | 正常游戏临时会话；死亡不构成跨局成长或存档机制 |
| 生命与复活 | 受伤后45成功tick无敌；耗尽回到记录的出生位置、满血并保护120tick | 没有装备防御、死亡掉落或复杂惩罚 |
| 怪物内容 | 蘑菇、哥布林、骷髅、飞眼、史莱姆、巨鼠、蝙蝠、宝箱怪 | 八种均为近战，尚无远程弹幕或格挡 |
| 怪物行为 | 地面巡逻追击与受阻跳跃；飞行追击；宝箱潜伏、唤醒 | 没有群体战术、阵营关系或长期目标 |
| 攻击判定 | 前摇结束时重查身体间距、朝向与地形视线；同一挥击一次伤害 | 暂停或缺地形不偷偷推进动作时间 |
| 构式伤害 | bolt对活怪物造成伤害，受击中断，死亡动画结束后删除 | Player/Resident无构式友伤；尸体不再拦弹 |
| 木头人 | 出生点右侧12格固定生成，保持身体命中框，可反复触发on_hit | 无生命、AI、移动或掉落；旧档载入不补生 |
| 居民 | Natural v2按地区适生率生成，拥有身体及头身双腿的简易几何呈现，离区休眠并恢复 | 暂无专用动画、AI、对话或生活玩法 |
| 呈现 | 主角分层动画、怪物动作图集和生命条读取完整提交 | F1不显示怪物/生命条；大量同屏怪物尚未优化 |

所有时间以成功的1/60秒固定步推进；暂停、预算重试、必要地形缺失不会消耗相应活动时间。绘制次数不推进怪物行为或动画状态。

## 地区内容与长期状态

Natural v2 每512格设置固定地区锚点，按当地森林／沙漠／雪山权重和种类适生率筛选候选，再检查完整地形与身体占用。候选不保证全部生成；死亡或被删除的身份保留墓碑，回访不会补生。

离区居民与怪物保存原身份、身体、生命和动作状态，重返恢复；不补算离区时间。当前地区候选容量上限16384，活动Actor容量256。Flat／Natural v1保留初始场景候选规则。详见[世界生态群落](WorldBiomes.md)。

持久能力仅在显式 Persistent 会话中使用。当前 Gameplay 存档写v6、读v1～v6，包含地区候选、墓碑和休眠对象；正常游戏 Temporary 模式重启重新创建世界。恢复需匹配怪物内容定义，不把缺失或未知定义替换成其他种类。

## 玩家和内容制作入口

- 正常模式：左键使用手持物：木棍释放其构式、方块放在面前；右键开采，Shift＋左键同样使用手持物；UI、元素笔刷和设备工具先处理输入。
- F2先掉落木棍并走近拾取，F4向当前手持木棍装载预设或编译／应用源码；装载不发射。木头人用于比较命中、开采和延时组合。
- [Monsters.json](../../Pixel/Content/Monsters.json)：行为数值、碰撞盒、地区候选、适生率及动作映射；修改后重新启动读取。
- [怪物资源说明](../../RawData/Monsters/README.md)：原图、动作网格与许可；运行时使用Content中的拷贝和来源清单。

## 依赖与责任

Gameplay/Actors管理身份、身体和组件，Gameplay/Ecology管理地区生命周期；Simulation只提供地形、群落和环境查询。Render只读提交快照。构式宿主通过结算入口伤害怪物，不能在绘制阶段修改生命。

Actor、BodyComponent、FormulaComponent、MonsterComponent和HealthComponent已经落地；这不是通用ECS或自动持久化框架。新增动物、NPC或敌人应复用身份入口，明确各自的组件、活动规则、值快照和保存策略。

## 验收切面与证据

- 体验：能辨认察觉、前摇、命中、受击、死亡和复活；隔墙与移出范围能避免攻击。
- 守恒：死亡不重复生成；休眠恢复不换身份、重置生命或重播奖励；构式命中一次只结算一次。
- 时钟：暂停、预算等待与缺块时冻结，恢复后按剩余时间继续。
- 呈现：碰撞身体与动画脚底一致，快照同帧，透明边缘和两种朝向可读。
- 边界：主要测试入口为 `Pixel.Monsters`、`Pixel.Actors`、`Pixel.Population`、`Pixel.Checkpoint`、`Pixel.ModuleBoundaries`，以及 `PixelRuntimeSmoke --monsters-only`。
