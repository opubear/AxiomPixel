# 画面、交互与内容资产

状态核对：2026-11-10。本文按玩家可见内容组织现状与交付边界；美术资源的加入、运行时接线和实际画面验收是三个分别确认的步骤。

## 玩家体验与目标

画面应让玩家辨别地区、材料、生物和动作结果；普通游戏界面服务操作，调试视图服务开发验证。世界缩放、UI缩放和世界物理尺度独立，改变画面大小不能改变碰撞或资源规则。

## 显示与输入边界

- `GameConfig.json` 的 `SceneScale` 与 `UIScale` 独立控制场景与UI显示；连续空间仍为每格50厘米，见[空间单位](../../Docs/WorldUnits.md)。
- 键鼠由 Input 适配到 Gameplay；点击使用输入事件自带的鼠标与窗口快照。Gameplay核心不依赖Input、Render或ImGui。
- 渲染消费自持有的冻结帧；世界、权威角色、物品、构式和UI应解释同一提交；玩家显示位置另有预测推进。角色预测仅用于呈现，权威碰撞和保存仍属于模拟。
- 场景完成后先经过后处理，再叠加原生UI与开发UI；UI不受场景调色影响。
- F1隐藏普通场景效果，用方向颜色诊断力场；它不表达强度，也不代替普通画面的体验验证。

三线程、帧槽、发布与关闭合同见[隔帧并行](../../Docs/Architecture/ParallelFrames.md)和[独立模拟线程](../../Docs/Architecture/SimulationThread.md)。

## 资产管理与交付

| 位置 | 管理用途 | 分发含义 |
|---|---|---|
| `ArtRaw/` | 早期第三方原包、许可、候选与生成原件 | 本地素材目录被Git忽略；索引可读不代表全新checkout拥有原包 |
| `RawData/Materials/Biomes` | 新群落材质原件、制品、提示词、校验和恢复脚本 | 保留全部可复制的64像素制品 |
| `RawData/Environment/Biomes` | 沙漠／雪山原件与2560×1440制品 | 可校验并恢复当前背景 |
| `RawData/Monsters` | 怪物原包、许可、动作清单与预览 | 运行接入使用整理后的制品与清单 |
| `Pixel/Content` | 运行时PNG、游戏资产JSON与来源映射 | 游戏只读此处；PNG和许可复制件按当前规则被Git忽略，发布包须单独携带 |

每次新增或替换资源应保留来源与许可／生成记录，更新 `SOURCE.json`、配置与哈希，并检查真实尺寸、动作网格、透明边缘及实际游戏效果。生成素材应注明工具与提示词，不将生成来源描述为第三方许可。候选库中的攻击特效或装备素材没有经过接线时只属于候选。

已有恢复入口：

```sh
python3 RawData/Materials/Biomes/install_runtime.py
python3 RawData/Environment/Biomes/install_runtime.py
```

怪物来源与恢复见[怪物素材说明](../../RawData/Monsters/README.md)。旧森林背景、自然材质和玩家仍依赖本地ArtRaw原件及其记录，目前没有覆盖所有运行资产的统一恢复命令。缺失资源应报告并恢复，不能静默用候选图或空白替代。

共享资产缓存避免反复解码和上传；成功载入的资源目前不支持热更新或逐出。新大图要核对CPU解码、上传缓冲和GPU三份成本；World的512MiB预算不包含这些美术资源。

## 后续内容与体验决策

| 待交付范围 | 前置决策 | 验收要点 |
|---|---|---|
| 玩家正式交互 | 将哪些F2/F4功能转成玩家可理解的操作；新手路径与反馈 | 不依赖调试术语即可完成观察、施放、建造与查看失败原因 |
| 装备与攻击动画 | 装备规则、图层插槽、工具／武器状态及事件时机 | 视觉与真实命中、资源消耗和角色状态一致 |
| 地区声音 | 音频资源、地区键映射、滞回与淡入淡出 | 按玩家所在地区切换，不能按GPU背景层数决定 |
| 背景扩展 | 沙漠／雪山是否需要独立多层视差、地下景观与重复策略 | 交界连续、远坐标稳定、构图重复可接受 |
| 资产可复现分发 | 旧ArtRaw依赖、许可携带与统一安装入口 | 干净环境能准备完整Content并启动，而非只有JSON通过检查 |

当前没有BGM资源或播放逻辑；以上条目是待决策范围，不是已承诺的版本内容。

验证按改动选择 ArtAssets、TerrainAssets、CharacterAnimation、Monsters、Biomes、InventoryUI、PixelScale 和相关输入专项；视觉改动追加对应原生GPU smoke与实际画面检查。历史结果见各合同带日期章节，本次文档整理没有重新生成素材或运行GPU。
