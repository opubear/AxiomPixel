# 风场策略首版 — 2026-10-12

用户确认范围：程序化风、粗 NS＋局部模型、自适应 NS、CPU D2Q9 LBM 四类首版；保留原粗场和逐像素 baseline。LBM 本轮不实现 GPU，方块仍使用已有固定步长、死区与邻格运动规则。

## 职责与切换

- `WindStrategy`：纯空气速度、推进、几何同步、脉冲及材料表面采样契约；策略拥有全部模拟数据，不保存外部 WorldStateView。
- `WindSimulation`：独占一个策略，先构造新策略再替换，非法设置不改变原状态；关闭后不贡献空气速度。
- `World::ConfigureWindStrategy` 与 ImGui `Wind strategy`：统一选择六个版本。重配置重建风，不保存各版本历史进度；材料、基础力场不变。
- `ForceField`：独立空间加速度，完全不依赖风。Environment 经 `FieldResponse` 把风速转为材料受力，再与基础场相加；重力、其他源与风不会共用模拟状态。
- 旧 `ConfigureWind` / `ConfigurePixelWind` 与粗场/reference诊断接口继续保留。纯风用 `SampleWind`，合成受力用 `GetForce`。固体纯风为零（旧粗场例外），材料响应采样暴露空气。

World、数值后端均无渲染或引擎依赖。本轮未修改本地引擎，也未写入相邻 `../Axiom`。保留用户原有未提交 baseline；审查基线为开始工作时保存的 Pixel 源码快照。

## 四类实现

### 程序化与混合

`ProceduralWindField` 用确定种子和连续时间的正交剪切阵风，另存可衰减的脉冲场。无障碍解析阵风无散；脉冲和局部障碍修正不保证无散。

`LocalWindGeometry` 用周期八邻域多源距离带寻找近似最近障碍，影响半径 1～32 像素；迎风侧减速/偏转，背风侧衰减。重建与像素数线性相关，采样常数成本，内部材料不重复叠加尾流。纯程序化不传播障碍扰动的历史；混合方案由粗场保留演化和真实泥土速度反馈，局部修正仅用于采样，不重复写回阻力。

这是可控近场近似，不保证法向精确为零、不可压缩、多障碍流量分配或封闭空间通风。固体编辑与移动在固定步前后同步，暂停后编辑到下一模拟步才更新几何，与 baseline 一致。

### 自适应 NS

`AdaptiveWindField` 从默认 8×8 块开始，混合空气/固体块沿长轴二分，直到空气叶均匀、固体剔除，必要处细化到像素。像素归属图保留几何；粗细交界每段面只保存一份通量，压力通过一个全域图拉普拉斯 PCG 系统求解。封闭固体面通量为零；周期外边界仍可连通。

先显式扩散，再用共享面上风通量输运动量，按实际出流量/叶体积限制 CFL；随后对共享面投影并重建中心速度。采样为叶内常量。提供确定的 `SetVelocities` 初态与压力迭代/RMS/最大散度报告。报告散度是共享面通量散度，不能冒充显示采样场的差分散度。

限制：首阶输运、强数值扩散、非正交粗细界面的中心距离近似、重网格的速度平均/新空气初始化误差；没有高阶重建、误差驱动细化或严格移动壁面。密集碎片可能接近逐像素，没有以预算截断物理区域。最大维度 2048，块大小 1～32，物理参数沿用 reference 契约。

### CPU LBM

`LbmWindField` 使用逐像素 D2Q9 BGK、周期迁移和固体 halfway bounce-back，固定 lattice 时间累积，与渲染帧率解耦。默认 lattice 步长 1/600 秒、背景风30、阵风10，区别于其他策略的默认90/60。设置要求初始 lattice 速度不超过0.2。

碰撞时间 `tau` 下限0.51，报告有效黏性；平衡分布使用低马赫速度限制，负分布恢复为同密度平衡分布，并累积报告稳定化次数。静态障碍测试质量守恒；移动/编辑会移除或重建空气，因此不承诺动态总质量或动量守恒。弱可压缩、速度限制及恢复的原型，不是高精度无散解，也尚无GPU实现。

- Debug CTest 7/7、ASan/UBSan CTest 7/7。独立验证代理在最终平流修复后重新构建并执行。
- 六策略切换、非法参数事务性、力场叠加/隔离、范围外采样、帧率一致性、几何放置/移除、零脉冲与非法脉冲回归。

## 成本样本与复现

可执行目标 `PixelWindStrategyBenchmark`，命令见 README。统一背景8、零阵风/松弛，黏性8，静态几何；64×32运行4步，1024×512运行1步（跳过昂贵reference），均为 RelWithDebInfo。包含策略推进与前后几何同步/反馈，不包含材料移动、渲染、GPU。单次、无统计置信度，而且测量与构建/测试在同机发生，不能据此承诺实时性能。
