CONFIG expands to each of Debug and RelWithDebInfo; VARIANT expands to baseline, direct, cached, counters. The terrain_plus_one scenario was added after the first seven timing scenes and measured separately. A fresh run of the saved runner includes all eight timing scenes.

Boundaries:
Counts are measured in a separate instrumented executable and are not timing results.
Cached destinations are built once before warmup; construction cost is recorded separately. Invalidation, dynamic wind, and production integration are absent.
Timing excludes cache preparation, world hashing and CSV output. No game presentation, frame pacing, GPU execution or user interactions are included.
Hash checks concern end states, not complete per-step equivalence for a proposed production optimization.
Existing contract tests link only the original material algorithm; they do not certify the restricted variants for arbitrary inputs.
No full application/GPU regression suite was run; no production files were modified by this investigation.
