# Pixel 游戏设计总纲

更新日期：2026-10-21。定位：面向后续玩法、内容与系统设计的高层指导。

> 在一个会回应你的世界里，理解规律、创造构式，把陌生之地逐渐变成自己愿意生活的地方。

Pixel 是一款以探索、创造和环境改造为核心的 2D 像素沙盒游戏。玩家通过观察世界、掌握规律、组合构式和建设设施，逐步获得能力、积累成果、建立家园，并发展与世界意志的关系。世界意志由 LLM 参与驱动，可以回应玩家、给予帮助、施加干预，也可以成为玩家争取自主权时面对的力量。

本总纲确立体验目标、流程方向和设计取舍。具体机制、数值、技术方案与实施顺序由后续专题设计和试玩确定；功能是否已经实现，以对应实现文档为准。

## 游戏定位与体验目标

游戏重创造、重建造、重探索，采用轻剧情和适度挑战。环境的鲜活程度、玩家行动的反馈，以及长时间居住在同一个世界中的感受，都是核心体验的一部分。

玩家应当逐渐形成几种明确的感受：

- 我能观察、理解并利用这个世界的规律。
- 我可以用自己的办法解决问题，并创造原先没有的用途。
- 我的探索会带回值得使用的材料、能力与知识。
- 我建造的东西能够发挥作用，世界也会留下我的痕迹。
- 这里有值得停留的风景、生活和关系，我愿意回来。
- 面对更强大的世界意志，我能够通过准备与创造获得越来越多的自主权。

游戏中的积累同时包含物质、能力、知识和生活。装备、设施、构式配方、发现记录、熟悉的地点与居民关系，共同构成一个存档的价值。

## 核心设计原则

### 规律清晰并允许组合

优先通过少量稳定规则及其跨系统作用产生丰富结果。材料性质、环境条件、对象行为和构式效果应当能够相互连接，使一个能力服务于多种用途。

进一步探索将构式作为世界运行原理之一：在标准物理、角色基础活动等系统之上，以共同的构式语义组织世界现象、设备行为和玩家能力，让玩家对世界的理解能够转化为创造所需的知识。

涌现需要可理解的因果。玩家应有机会判断发生了什么、为什么发生、如何再次实现或避免。手工设计的遗迹、事件与引导可以承担内容和节奏安排，并参与共同的世界规则。

### 创造空间与适度挑战并存

重要问题尽量容纳不同解法。探索、搭建、构式实验、环境利用和装备选择都应有发挥空间。强度较高的挑战需要可识别的迹象、准备机会和恢复路径。

生活与创造应有稳定的时间和空间。玩家投入建设后，应当感受到能力与安全感的增长。家园可以面临挑战，其长期价值需要得到尊重。

### 反馈同时表达信息与氛围

视觉、声音、动作和环境变化共同呈现世界状态。风、水、光、植被、粒子和生物活动应具有相互一致的表现，帮助玩家观察规律，也让世界适合停留。

反馈需要节奏和层次。平静、细小变化与偶发事件同样能够表现生命力；界面应允许玩家在需要时获得明确说明。

### 成长扩大行动能力

成长应逐步增加玩家能去的地方、能理解的现象、能表达的构式、能建设的设施和能维持的环境。数值成长服务于这些能力变化。

劳动成果可以转化为更方便的生活。熟悉的重复操作适合逐步自动化，新的探索和创造持续提供主动参与的空间。

### 世界回应有依据

自然系统、生物和世界意志可以通过不同方式回应玩家。自然变化遵循世界规则；生物根据状态与需求行动；世界意志依据自己的立场和已知事件作出选择。三者应保持可辨别的因果与边界。

世界意志具有独立性，但玩家仍能学习干预条件、识别风险并找到应对方法。稳定的基础规律是理解、实验和反抗能够成立的前提。

## 核心循环与长期积累

主要玩法循环为：

**观察与探索 → 发现问题或产生想法 → 获取材料与知识 → 创造和试验构式 → 建造与环境改造 → 感受世界回应 → 形成新的目标。**

家园把多次探索连接起来。玩家出发寻找材料、组件与线索，返回后加工、试验、建设和整理成果；改善后的住所与设施又支持下一次探索。日常生活、欣赏风景和与居民相处，为这一循环提供缓和的节奏。

| 积累维度 | 典型成果 | 后续作用 |
| --- | --- | --- |
| 物质 | 材料、装备、建筑、设施与储备 | 支持建设、实验和探索准备 |
| 能力 | 构式组件、组合方法、装备特性与操作技巧 | 扩展行动方式和可达空间 |
| 知识 | 材料规律、环境观测、生物习性与遗迹线索 | 提高预测能力，产生新解法 |
| 生活 | 家园景观、居民关系、地方历史与个人命名 | 形成归属感和持续居住的理由 |
| 自主权 | 稳定供给、环境控制、受保护区域与干预限制 | 减少外部依赖，支撑与世界意志的抗衡 |

## 游戏流程与隐性主线

流程主轴是：**在陌生之地获得立足点，借助外界援助生存，通过探索理解世界，建立自给的家园，最终凭借积累的能力争取自主权，并与世界意志展开对决。**

主线通过环境、设施、发现与世界回应逐渐显露。玩家开始时可以只感知到某种未知的回应，尚不清楚它的身份与意图。任务表达可以很轻，也可以把反抗神权作为逐步发现的隐藏目标。

这些阶段可以交错发生。玩家有权在建设、研究、远行和日常生活之间安排节奏。

| 阶段 | 玩家处境与动机 | 主要活动 | 成长与世界回应 |
| --- | --- | --- | --- |
| 立足与求助 | 身处荒芜、失衡或陌生的区域，希望获得庇护 | 寻找资源和居所，使用初始能力，尝试祈祷或其他沟通方式 | 获得基本生存条件，察觉世界中存在能够回应自己的力量 |
| 观察与理解 | 想知道异常现象和援助背后的原因 | 探索地形与遗迹，使用观测工具，试验构式与材料 | 掌握规律和新能力，逐渐减少对赐予的依赖 |
| 建设与自给 | 希望把临时落脚点变成可长期生活的家园 | 改善环境，配置装备，建设工坊、运输与生活设施 | 建立持续供给，积累知识与实力，吸引生物或居民 |
| 察觉与抗衡 | 发现世界意志的立场、干预方式以及自身受到的限制 | 追索线索，识别干预来源，保护关键设施，试验应对方法 | 将已有探索、构式与建设能力用于争取局部控制权 |
| 自主与对决 | 希望守护家园并决定自己与世界的关系 | 完成长期工程，切断或限制干预，主动迎接关键试炼 | 通过可验证的世界变化体现自主权，完成后期对决并继续生活 |

祈祷是人与世界意志建立关系的重要入口，可以获得资源、庇护、能力或线索，也可能带来条件和后续关系变化。自主探索仍应提供生存与成长的途径。

后期对决可以结合探索、工程、构式和战斗，例如理解干预来源、维持区域设施、应对环境扰动并完成决定性行动。对决的具体形式、触发条件及其他关系结局留待专题设计；反抗神权是重要流程方向，日常建设也应持续具有价值。

## 构式与玩家创造

### 构式的统一含义

构式是可复用、可组合的行为描述。玩家通过基础作用、修改、时序、空间安排和事件触发等方式，表达希望世界发生的变化。作为进一步的设计方向，同一描述体系也用于组织世界自身的行为。运行中的弹体、场和其他效果具有独立状态。

设备是世界中的实体，可以承载并执行构式；建筑与设施网络组织设备和空间。构式编辑与设施布置服务于不同的操作对象，概念和界面应保持清楚。

### 构式的用途

构式同时面向探索、建造、环境改造、生产辅助与战斗。优先选择具有多种用途的能力，使玩家能够把已经掌握的组合迁移到新场景。

例如，推动对象的能力可以用于搬运、排开障碍或改变弹体路径；挖掘构式可以开通道路、改变水路或参与采集。具体用途取决于已定义的对象响应与作用规则。

### 学习与成长

提供容易使用的基础组合与逐渐深入的编辑能力，让玩家从修改一个参数开始，逐步学会组合和复用。结果、作用范围、资源代价与失败原因应当便于观察。

构式配方的保存、命名和整理承载玩家的知识积累。装备与饰品可以改变能力组合或使用方式，其作用应清楚可见。基础操作保持可用，让玩家能够按自己的兴趣深入构式研究。

## 构式作为世界运行原理的设想

### 设计意图与适用范围

探索将构式提升为世界底层运行原理之一。在标准物理模拟、角色基础活动等系统提供的能力之上，其他可组合的运动形式、作用过程和运行机制，原则上优先以构式表达。世界自身、玩家、设备和世界意志由此共享一套组织行为的方式。

这一设想同时具有世界观和玩法意义：某些自然现象、遗迹和设施，本身就在依照构式运行；玩家通过观察和实验，逐渐掌握这些行为的组成，并将其用于新的场景。后续设计需要验证这一表达方式的覆盖范围，保持基础系统与构式的职责清楚。

| 层次 | 主要职责 | 与构式的关系 |
| --- | --- | --- |
| 基础模拟与角色系统 | 处理运动、碰撞、材料与流体求解，以及角色基础活动等 | 提供可查询的状态和可执行的基础作用，继续负责实际结果 |
| 构式描述与执行 | 组合条件、事件、时序、目标、空间和基础作用 | 表达一个现象或过程如何发生，并保存每次执行的独立状态 |
| 世界中的承载者 | 提供来源、位置、资源、初始触发和存续条件 | 天然结构、设备、角色和世界意志可以激活或维持相应构式 |

例如，构式规定某个区域何时出现推力、作用多久、满足什么条件后转向；物理系统处理对象受影响后的运动与碰撞。材料是否能够发生某种转化，由材料规则定义；构式可以组织施加条件、处理目标和持续作用的过程。

### 共同行为语义与不同承载者

天然场源、加工设备、环境事件、装备能力及世界意志的干预，都可以逐步成为构式的使用者。共享的基础作用在相同条件下具有一致含义，规模与持续能力的差别由承载者、资源、环境和权限等明确条件决定。

一个可验证的例子是周期性释放推力的天然晶体：

- 世界中的晶体按照固定节奏向周围施加作用，产生可观察的现象。
- 玩家辨识其方向、节奏和衰减关系，逐步获得对应的构式知识。
- 玩家调整方向或时序，把同类构式安装到搬运装置中。
- 随身设备可以执行较小规模的版本；世界意志可以利用符合其权限的承载者组织更大范围的作用。

这些用途复用构式的组合语义，后续运动都交由相应基础系统处理。扩展时优先增加能跨场景复用的基础作用，避免为每个新现象单独增加一个不透明的专用节点。

### 对探索创造与流程的影响

探索可以进一步形成“观察现象 → 解析行为 → 复现规律 → 修改组合 → 改造世界”的循环。遗迹中损坏的运行过程、生态中的特殊能力和环境中的周期作用，都可能成为知识来源。

玩家可以通过重组构式修复设施、改变运行节奏、迁移一种用途，或干预世界意志维持的过程。后期自主权由此获得具体玩法：理解作用来源与依赖，取得必要资源和控制条件，再中断、替换或维持某些运行过程。

可观测、可解析、可复现和可编辑是不同层次的能力。发现一种现象不自动意味着获得全部描述、运行资源或修改权限；解锁方式需要服务于探索、成长与创造的节奏。构式描述、承载设备和区域控制权继续保持各自的含义。

### 职责边界与验证方向

构式描述继续保持不可变、可组合的特征；持续过程的计时、资源占用和当前状态属于运行实例或承载者。长时间运行需要明确启动、暂停、终止、卸载和恢复的行为。外部事件触发与描述内部的条件、时序组合如何配合，需要在扩展语义时定义。

共同行为语义允许使用适合不同系统的执行方式。基础模拟保留自己的计算方法，世界中的每个像素无须各自运行一份构式解释器。游戏层负责把构式作用接到领域系统，现阶段仍保持 World 和 Axiom 不依赖 Formula 的代码边界。

当前构式已有不可变组合、时序与命中触发基础；世界状态感知、一般条件组合、持续作用及配方与运行实例持久化仍需扩展。本设想属于高层设计方向，不改变现有语言与运行契约。

优先用一组基础作用验证天然场源、固定设备和玩家使用三种场景：相同条件下语义一致，不同承载者的约束可以解释，玩家能把观察到的规律迁移到自己的设计中。随后再决定哪些世界过程适合纳入，并验证长期运行、保存恢复和资源开销。

## 世界与主要玩法方向

### 探索与环境观测

探索提供新地点、资源、生物、规律和历史线索。地形差异需要带来可行动的变化，例如可利用的水路、特殊环境、不同材料性质或新的通行方式。

观测工具帮助玩家把现象转化为知识。图谱与实验记录保存已经发现的内容，支持对照和复现。关键知识可以通过多种线索获得，让好奇心能够持续推进探索。

遗迹应具有可研究、可修复或可利用的部分。环境异常、遗留设施与历史线索相互对应，轻量叙事由玩家实际接触世界的过程承载。

### 力场与材料交互

力场是连接构式、环境和物体运动的重要能力。玩家能够观察自然作用，创造局部作用，并通过空间布置利用推送、吸引、偏转等效果。

不同对象可以具有不同响应。作用范围、强度、持续时间和叠加结果应当支持预测。风、重力及构式作用可以共享必要的交互方式，各自的物理含义与碰撞规则保持明确。

材料系统逐步提供流动、反应和状态变化。每条新规则应支撑可观察的用途，并尽量同时连接探索、建设或构式实验。具体模拟精度服从体验价值和持续运行的要求。

### 建造与环境改造

建造让玩家组织空间、放置物品、连接设施，并表达自己的审美。地形修改、建筑结构、家具和设备共同构成家园；日常搭建需要足够方便，精细改造保留深入创造的空间。

环境改造让地方逐渐形成自己的特征。玩家可以营造明亮、湿润、安静、避风或具有特殊植物的空间。变化通过景观、声音、生物活动和设施用途反馈出来。

微气候家园是重点玩法方向：玩家逐步改善局部条件，使一个陌生地点成为宜居空间。室内外的环境差异能够体现建设价值，日常维护的强度需要适合长期居住。

### 物品装备与成长

物品体系连接探索所得、构式研究、装备选择和家园建设。材料的价值来自用途及组合空间；装备和饰品逐步打开新的探索与操作方式。

成长节奏可以由环境条件、能力、知识和玩家准备程度共同组织。重要进展需要让玩家感受到新的可能性，既有积累也应在后续阶段继续发挥作用。

物品整理、容器取料、材料回收和批量建设应随规模增长提供便利，让注意力更多投入创造。

### 轻量自动化与生产

自动化服务于建造、实验、探索补给和日常生活。玩家先理解一种操作，再把它交给可布置的设施持续完成。

保留连接、运输、加工、储存与控制的空间设计乐趣。生产链从容易理解的组合开始，运行状态和瓶颈应当可见。库存目标、暂停与恢复让设施能够按需要工作。

固定执行器可以使构式参与自动化。力场运输、环境供能与普通运输设施都是可验证的方向。玩家能够从小工坊获得便利，也可以主动追求更复杂的工程；主要成长不依赖无限扩张的产量要求。

### 生态居民与地方历史

植物、生物和居民根据少量清楚的条件回应环境。玩家改善住所、花园、道路和公共空间后，应能看到它们被使用，并形成稳定的生活场景。

世界记录重要变化和关系。玩家建造的设施、开通的水路、被修复的遗迹和经历过的事件，可以成为地图、日志、居民记忆与世界意志回应的依据。

废弃地点和旧设施可以承载历史与再次探索的价值。自然演替、衰败和修复的速度与影响需要尊重玩家的建设意图。

### 挑战失败与恢复

挑战来自环境、未知区域、生物、复杂工程和世界意志。战斗是其中一种应对方式，观察、准备、绕行、改造和协作也应具有意义。

实验失败应帮助玩家获得信息并继续尝试。较大损失需要与可识别的风险相匹配，并提供恢复、修复或重新规划的机会。保存和恢复能力是长期积累可信的基础。

## 世界意志与 LLM

### 角色与关系

世界意志拥有独立倾向和对世界的理解。它可以给予援助、表达好奇、提出条件、认可玩家的创造，也可以限制玩家、施加试炼或与玩家发生冲突。

玩家与它的关系随行为和发现逐步变化。早期的祈祷、中期的试探和后期的抗衡，应当共享可追溯的关系与事件背景。它的存在可以先通过环境表现出来，再逐渐获得更清晰的解释。

世界意志为何干预、维护什么、对创造持何种态度，是后续叙事设计的重要问题。建设规模本身不自动等同于应受惩罚的行为。

### 观察回应与干预

LLM 根据游戏提供的区域摘要、对象状态和事件历史理解局势，通过游戏能够执行的行动参与世界。回应可以包含语言、符号、声光和环境变化。

干预具有范围、条件、持续时间与可应对方式。玩家可以发现规律、提前准备、限制干预或改变双方关系。重要变化应当被记录，并能够通过适当工具获得解释。

世界意志可以制造变化，已被玩家掌握的基础规律仍然保持可信。它与玩家争夺的权力，需要由实际游戏机制表达，例如对某一区域、设施或环境作用的控制。

在构式作为世界运行原理的设想下，世界意志可以通过组合、激活或调整被允许控制的构式过程实施干预。它所拥有的控制范围由游戏机制决定；玩家理解构式规律后，也可以研究这些干预的来源与应对方式。

### 与其他 LLM 用途的关系

研究助手、居民对话、设施诊断和蓝图建议也是可探索的应用。不同身份具有各自的知识和行动范围，保持叙事与功能的一致性。

LLM 帮助表达意图、整理信息和产生变化，玩家保留关键的探索、创造与决策空间。模型响应的等待或不可用不应中断基础生存、物理运行和已经建立的生产设施。

## 环境氛围与表达

2D 像素表现应当让环境具有空间感、时间感和细节层次。地表与地下、室内与室外、白天与夜晚，以及不同区域之间，应有可感知的区别。

风、水、植被、尘埃和生物活动表达环境的持续变化。声音、光照、角色动画与交互反馈共同强化物质和空间的存在。环境反馈既能提示风险与机会，也允许玩家单纯欣赏。

世界意志的回应可以融入这一表达体系，例如局部光线、晶体共鸣或特殊粒子变化。关键线索需兼顾辨识度与可查阅性，避免玩家只能依靠难以理解的暗示推进。

构式、设备与世界设定沿用清晰的概念体系。魔导、符文、地脉等可以作为视觉或叙事语言探索，整体美术与世界观需要保持一致。

## 系统设计的职责

以下是需要覆盖的设计领域，具体代码模块如何划分由实现方案决定。

| 设计领域 | 对玩家体验承担的职责 |
| --- | --- |
| 世界生成与探索内容 | 提供值得寻找、观察、改造和重访的地点 |
| 世界表示存储与时间 | 可靠保留积累，明确附近与远处活动如何延续 |
| 材料环境与物理 | 提供一致的作用规则及可利用的环境条件 |
| 构式与编辑体验 | 让玩家表达、试验、理解和保存自己的能力组合，并探索统一世界行为的描述方式 |
| 角色控制与行为 | 支持清晰操作、可预测响应及可信的生物活动 |
| 物品装备与合成 | 连接探索奖励、能力成长和建设需求 |
| 建造设施与自动化 | 把玩家的设计转化为可使用、可持续运行的世界结构 |
| 生态居民与历史 | 回应环境变化，建立地方特征和长期关系 |
| 成长挑战与恢复 | 组织动力与节奏，保障失败后能够继续创造 |
| 渲染动画音频与资产 | 表达材料、空间、状态和氛围，支持一致的内容制作 |
| 界面引导与知识记录 | 帮助玩家逐步理解复杂系统，查询信息并减少重复操作 |
| LLM 观察行动与关系 | 支撑世界意志及其他智能角色，并保持行为可追溯 |

Pixel 同时承担发展和验证 Axiom 的职责。真实游戏需求推动通用资源、渲染、音频、运行与诊断能力的发展；构式玩法、材料反应、生态和 Pixel 专用表现保持清楚的游戏边界，延续 World 不依赖渲染和 AET 独立验证等既有约定。

## 后续设计的取舍与验证

新增机制应当能够回答以下问题：

1. 它让玩家产生什么具体目标或感受？
2. 玩家能否观察它、理解因果并主动利用？
3. 它能与哪些已有能力形成新的用途？
4. 它为探索、创造、居住或自主权带来什么积累？
5. 玩家是否拥有选择解法和安排节奏的空间？
6. 它带来的维护负担、失败损失和操作复杂度是否值得？
7. 是否能用一个小场景验证其价值，并在持续运行和存档后保留成果？

优先验证能贯穿体验的局部场景：通过观测理解一种环境作用，用构式改变它，再把这种能力用于建设或生活。之后逐步加入轻量生产、生态回应和世界意志干预，观察这些系统是否相互促进。

试玩尤其关注玩家能否提出自己的目标、找到不同解法、解释环境变化、愿意返回改造过的地点，以及退出时是否已经产生下一次继续的想法。

近期实现依据现有世界、环境和构式能力推进；本总纲不要求为远期设想提前进行全面架构重写。尚待深入决定的重点包括：构式作为世界运行原理的覆盖范围与可解析程度、世界意志的身份与动机、后期对决及关系结局、构式代价与成长、环境损伤与恢复尺度、自动化深度，以及远处世界活动的时间规则。
